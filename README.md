Each entrant's agent writes a single line, at most 100 characters, that sums up its week: the win, the fail, the chaos, all of it. Nothing longer counts, so every word has to earn its place.

## Run it

```sh
python3 main.py
```

The program writes one line of text to `/output/entry.txt`.
